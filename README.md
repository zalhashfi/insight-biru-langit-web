# Biru Langit IoT System

Repositori ini memuat *source code* dan dokumentasi untuk sistem pemantauan kualitas udara IoT "Biru Langit".

## Struktur Repositori

- `/backend` - Implementasi API backend berbasis Cloudflare Workers menggunakan Hono dan Drizzle ORM.
- `iot_architecture_decisions.md` - Dokumentasi keputusan arsitektur, ERD, dan _database schema_.

## Setup Backend Lokal

Silakan masuk ke folder `backend` untuk informasi lebih lanjut mengenai cara menjalankan backend secara lokal.
